# Attendance Management System using Face Recognition

## Overview
This is an **Attendance Management System** that uses **face recognition** to automatically mark student attendance.  
It allows you to capture student images, train the model, and mark attendance automatically or manually.

---

## Features
- Capture student images for face recognition
- Train face recognition model
- Automatic attendance marking via webcam
- Manual attendance entry option
- View attendance records in a table
- Simple and user-friendly GUI

---

## Requirements
- Python 3.12+
- Libraries:
  - `opencv-python`
  - `numpy`
  - `pandas`
  - `face-recognition`
  - `pillow`
  - `pyttsx3`
- `tkinter` (comes pre-installed with Python on Windows)
